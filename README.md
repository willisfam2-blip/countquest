# CountQuest — Grade 1 Counting Game

A bright, voice-guided counting game for Grade 1 children (6–7). Includes 6 progressive short levels (counting, number recognition, add/subtract), large tappable UI, voice instructions via SpeechSynthesis, sticker rewards, parental progress notes, and a downloadable CSV question bank. Self-contained static MVP you can open locally.

## Setup
Unzip and open index.html in a browser (Chrome/Edge/Safari). Works offline. For best experience use a tablet or phone. The app uses the browser SpeechSynthesis API for voice instructions; allow audio when prompted.
